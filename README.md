# ppt-package-manager-for-archlinux
PPT - It’s a merger of AUR and pacman into a single package manager.


HOW TO RUN PPT - sudo curl -L https://github.com/hoxi-boiled/ppt-package-manager-for-archlinux/releases/download/PPT/package_processing_tool.sh -o /usr/local/bin/ppt && sudo chmod +x /usr/local/bin/ppt
